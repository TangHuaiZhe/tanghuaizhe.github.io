一、如何证明素数有无穷多个？

素数（Prime number）是大于 1、只有 1 和自身两个正因数的整数。例如 2、3、5、7、11。1 既不是素数也不是合数。

证明素数有无穷多个，最经典的方法是欧几里得证明（Euclid's proof）。它诞生于两千多年前，几乎不需要任何高等数学知识，却非常巧妙。

第一步：假设素数只有有限多个

采用反证法（Proof by contradiction）。假设世界上所有素数都已找到，共有 \(n\) 个，按大小排列为：

\[p_1,p_2,p_3,\ldots,p_n\]

也就是 \(2,3,5,7,11,13,\ldots,p_n\)，其中 \(p_n\) 是世界上最大的素数。

第二步：构造一个新整数

把所有素数乘起来，再加 1：

\[N=p_1p_2p_3\cdots p_n+1\]

为什么要加 1？这是整个证明最巧妙的地方。乘积恰好是每个已有素数的倍数，加 1 后就避开了所有这些倍数。

第三步：用已有素数整除 N

\[\begin{aligned}N\bmod p_1&=1\\N\bmod p_2&=1\\&\vdots\\N\bmod p_n&=1\end{aligned}\]

也就是说，我们假设存在的所有素数都无法整除 \(N\)，余数永远是 1。

第四步：产生矛盾

任何大于 1 的整数，要么本身是素数，要么能够分解成若干素数的乘积。因为 \(N>1\)，所以只有两种可能：

无论哪种情况，都意味着存在一个不在原列表中的新素数。因此最初的假设不成立。

\[\boxed{\text{素数有无穷多个}}\quad\square\]

这里真正依赖的是每个大于 1 的整数至少拥有一个素因子：如果一个合数的因子还不是素数，就继续分解，直到找到素数。因为因子严格变小，这个过程必然结束。

这个证明为什么深刻？

欧几里得揭示了一个数学结构：任何有限的素数集合，都能被证明不完整。他不需要知道下一个素数在哪里，也不需要知道分布规律，仅利用整数的乘法和整除性质，就能证明素数永远不会被穷尽。

但这并没有回答：小于某个 \(x\) 的素数大约有多少个？实际分布与理论估计的误差有多大？是否存在无穷多对相差 2 的素数（孪生素数猜想，尚未解决）？这就引出了素数定理。

三、素数计数函数（Prime-counting function）

定义一个函数，统计不大于 \(x\) 的素数数量：

\[\pi(x)=\sum_{\substack{p\leq x\\p\text{ 为素数}}}1\]

这里的 \(\pi\) 与圆周率无关。例如 \(\pi(10)=4\)，分别是 2、3、5、7；\(\pi(100)=25\)；\(\pi(1000)=168\)。

随着 \(x\) 不断增大，素数计数函数持续增长，但相对于 \(x\) 而言增长越来越慢。素数定理描述的正是这种宏观分布规律，而不是给出下一个素数的位置。

四、素数定理的核心公式

素数定理（Prime Number Theorem, PNT）告诉我们：

\[\boxed{\pi(x)\sim\frac{x}{\ln x}}\]

\(x\) 是观察的数字上限；\(\pi(x)\) 是实际素数数量；\(\ln x\) 是以 \(e\approx2.71828\) 为底的自然对数；符号 \(\sim\) 表示渐近等价（Asymptotic equivalence）。

严格的数学表述是：

\[\boxed{\lim_{x\to\infty}\frac{\pi(x)}{x/\ln x}=1}\]

这意味着，当 \(x\) 趋于无穷大时，用 \(x/\ln x\) 来估计素数数量，其相对误差趋于零，而非绝对误差趋于零。

不要把渐近等价理解成相等。 两个数可以都很大，差值也很大，但它们的比值仍可非常接近 1。例如 \(x\) 与 \(x+\sqrt{x}\) 的比值趋于 1，差值却趋于无穷大。

六、素数密度与平均间隔

将素数定理两边同时除以 \(x\)：

\[\frac{\pi(x)}{x}\sim\frac{1}{\ln x}\]

左边是素数在前 \(x\) 个自然数中的占比。于是可将 \(\rho(x)\approx1/\ln x\) 理解为素数的近似密度。在适当的平均意义下，它也可描述 \(x\) 附近的整数成为素数的可能性。

小规模处的近似并不精确；这些柱状图给出理论密度，不是短区间的实测值。严格地，对于固定 \(\delta>0\)，区间 \([x,(1+\delta)x]\) 的素数数量渐近为 \(\delta x/\ln x\)。不能由此直接推出任意很短区间的素数数量。

反过来，密度的倒数就是典型的平均间隔尺度：

\[\boxed{d(x)\approx\ln x}\]

这里说的是平均尺度，不意味着每隔固定数量的整数就一定存在一个素数。事实上，可构造任意长的连续合数：对任意 \(m\ge2\)，整数 \(m!+2,m!+3,\ldots,m!+m\) 分别能被 \(2,3,\ldots,m\) 整除。故素数间隔没有固定上界。

七、更准确的公式：对数积分（Logarithmic integral）

如果接受素数的近似密度 \(\rho(t)=1/\ln t\)，那么从 2 到 \(x\) 有多少个素数？将区间内所有位置的密度累加起来。在连续数学中，累加对应积分：

\[\boxed{\operatorname{Li}_2(x)=\int_2^x\frac{dt}{\ln t}}\]

为什么积分比直接使用 \(x/\ln x\) 更准确？后者相当于用终点附近的密度去估算整个区间，而前面的素数密度更高，后面的密度更低。积分考虑了这种连续变化。

当 \(x=10^6\) 时，实际素数数量为 78,498，简单估计约为 72,382，对数积分（以 2 为起点）约为 78,626。简单估计相对误差约 7.79%，积分误差约 0.16%。对数积分通常提供更好的近似，但不保证每个 \(x\) 上都更准确。

常见的另一种记号 \(\operatorname{li}(x)=\operatorname{PV}\int_0^x dt/\ln t\) 采用柯西主值，与这里的 \(\operatorname{Li}_2(x)\) 仅相差常数约 1.04516。两者的大规模渐近性质相同。

分部积分可解释两种估计的关系：

\[\operatorname{Li}_2(x)=\frac{x}{\ln x}-\frac{2}{\ln2}+\int_2^x\frac{dt}{(\ln t)^2}.\]

继续展开，可得到 \(x/\ln x+x/\ln^2x+2x/\ln^3x+\cdots\) 的渐近展开（固定截断阶数，并非对固定 \(x\) 的收敛级数）。首项就是素数定理的简单估计。

\[\pi(x)\sim\operatorname{Li}_2(x)\sim\frac{x}{\ln x}\]

九、为什么偏偏是自然对数？

为什么素数数量不是 \(x/\sqrt{x}\)，或者 \(x/\ln^2 x\)，而偏偏是 \(x/\ln x\)？这涉及黎曼 ζ 函数与欧拉乘积。

1. 黎曼 ζ 函数（Riemann zeta function）

\[\zeta(s)=\sum_{n=1}^{\infty}\frac1{n^s}\qquad(\operatorname{Re}s>1)\]

当 \(s\) 的实部大于 1 时，根据欧拉乘积（Euler product）：

\[\boxed{\zeta(s)=\prod_{p\text{ 为素数}}\frac1{1-p^{-s}}}\]
\[\zeta(s)=\frac1{1-2^{-s}}\frac1{1-3^{-s}}\frac1{1-5^{-s}}\cdots\]

这建立了整数的加法表达与素数的乘法表达之间的桥梁。数学家不需要直接研究每一个素数，而可以借助连续复变函数间接获得素数信息。

2. 欧拉乘积为什么成立？

使用几何级数：

\[\frac1{1-p^{-s}}=1+p^{-s}+p^{-2s}+\cdots.\]

将每个素数对应的级数相乘，每个整数 \(n\) 根据唯一素因数分解 \(n=\prod_p p^{k_p}\) 恰好出现一次，对应项为 \(n^{-s}\)。在 \(\operatorname{Re}s>1\) 时绝对收敛保证这种展开合法。举例，\(12=2^2\times3\)，所以 \(12^{-s}=2^{-2s}3^{-s}\) 恰好来自这两个因子的对应项。

如果说自然数像建筑物，素数就像构成建筑物的基本积木；欧拉乘积把这种离散的乘法结构编码进一个函数。

十、素数定理的经典证明思路

以下是证明路线，而不是完整的复分析严格证明。1896 年，阿达马（Hadamard）和德拉瓦莱·普桑（de la Vallée Poussin）分别证明了素数定理。

第一步：取对数再求导

\[\ln\zeta(s)=-\sum_p\ln(1-p^{-s})=\sum_p\sum_{k=1}^{\infty}\frac{p^{-ks}}k\]
\[-\frac{\zeta'(s)}{\zeta(s)}=\sum_p\sum_{k=1}^{\infty}\frac{\ln p}{p^{ks}}\]

这里在实数 \(s>1\) 或选定适当解析对数的右半平面成立。自然对数 \(\ln p\) 出现了：对指数项 \(p^{-ks}=\exp(-ks\ln p)\) 求导自然产生 \(\ln p\) 权重。

第二步：引入切比雪夫函数（Chebyshev function）

\[\psi(x)=\sum_{p^k\leq x}\ln p,\qquad \theta(x)=\sum_{p\leq x}\ln p.\]

前者对素数及其幂加权统计，后者仅对素数本身加权。也可定义冯·曼戈尔特函数 \(\Lambda(n)=\ln p\)（若 \(n=p^k\)），否则为 0，从而 \(\psi(x)=\sum_{n\le x}\Lambda(n)\)。

\[-\frac{\zeta'(s)}{\zeta(s)}=\sum_{n=1}^{\infty}\frac{\Lambda(n)}{n^s}\]

第三步：ζ 函数在 Re(s)=1 上没有零点

ζ 函数在 \(s=1\) 处有一个简单极点，而在直线 \(\operatorname{Re}(s)=1\) 的其余点上没有零点。结合适当的分析方法（现代证明常采用 Tauberian theorem，即陶伯定理），可以由该极点及边界性质推出：

\[\psi(x)\sim x\]

这是经典证明的实质性难点。不能仅凭欧拉乘积或 \(\ln p\) 的出现，就断言素数定理已经被证明。

第四步：去掉高次素数幂

每一个满足 \(p^k\le x,\ k\ge2\) 的素数必满足 \(p\le\sqrt x\)。对每个素数，高次幂贡献不超过 \(\ln x\)，因此总贡献至多为 \(\sqrt x\ln x=o(x)\)。所以：

\[\psi(x)-\theta(x)=O(\sqrt x\ln x),\qquad \theta(x)\sim x.\]

第五步：消除对数权重，得到素数计数函数

使用分部求和（Partial summation），把每一个 \(\ln p\) 的权重乘以 \(1/\ln p\)：

\[\pi(x)=\frac{\theta(x)}{\ln x}+\int_2^x\frac{\theta(t)}{t(\ln t)^2}\,dt.\]

由于 \(\theta(x)\sim x\)，第一项渐近等于 \(x/\ln x\)，第二项为 \(O(x/\ln^2x)\)，相对较小（可将积分在 \(\sqrt x\) 处分段验证）。故：

\[\boxed{\pi(x)\sim\frac{x}{\ln x}}\]

这也解释了为什么最后是自然对数：加权素数计数呈线性主趋势，解除自然对数权重后得到 \(x/\ln x\)。

补充：1949 年发表的 Selberg–Erdős 初等证明不依赖复分析；“初等”指使用的数学工具，不意味着证明简单。

十一、素数定理与黎曼猜想

素数定理告诉我们总体趋势；黎曼猜想进一步试图约束实际分布偏离这一趋势的程度。

定义误差函数：

\[E(x)=\pi(x)-\operatorname{Li}_2(x)\]

素数定理保证：

\[E(x)=o\!\left(\frac{x}{\ln x}\right)\]

小 o 符号表示误差除以 \(x/\ln x\) 后趋于零。黎曼猜想（Riemann hypothesis）则提出，ζ 函数的所有非平凡零点 \(\rho\) 满足：

\[\operatorname{Re}(\rho)=\frac12.\]

若黎曼猜想成立，可得到更强的误差界：

\[\boxed{E(x)=O(\sqrt{x}\ln x)}\]

大 O 表示对于充分大的 \(x\)，误差绝对值被某个常数倍的 \(\sqrt x\ln x\) 控制。这并不是说误差一定等于该表达式，也不是说每个素数的位置都能预测。黎曼猜想仍是未解决的数学问题。

为什么零点会影响素数分布？

黎曼显式公式的一种形式（对不处于素数幂跳跃点的 \(x>1\)，零点求和按适当的对称截断理解）为：

\[\psi(x)=x-\sum_{\rho}\frac{x^\rho}{\rho}-\ln(2\pi)-\frac12\ln(1-x^{-2}).\]

其中 \(x\) 是宏观主项，零点对应波动项。若 \(\rho=\beta+i\gamma\)，则 \(x^\rho=x^\beta e^{i\gamma\ln x}\)。因此实部决定波动项的增长尺度，虚部与对数坐标中的振荡相关。这是一种更具体的理解：在自然数的离散世界里看见的起伏，可以通过复分析中的零点表达；但这并不意味着素数已经被证明是某个物理高维几何物体的投影。

可类比物理学的统计力学：很难逐个预测气体分子的运动轨迹，但大量分子聚集时，却呈现精确的宏观规律。这个比喻只是帮助理解整体统计规律，并不暗示素数本身是随机运动的粒子。

欧几里得发现了素数的无限性，素数定理发现了素数的宏观秩序，而黎曼猜想试图揭示这种宏观秩序背后的精细结构。

动手验证：用 Python 实现埃拉托斯特尼筛

程序员可以直接通过筛法计算有限范围内的真实素数计数。时间复杂度约为 \(O(x\log\log x)\)，空间复杂度为 \(O(x)\)。它能验证数值趋势，但不能替代无穷范围的数学证明。

from math import isqrt, log

def prime_count(n):
    if n < 2:
        return 0
    sieve = bytearray(b'\x01') * (n + 1)
    sieve[0:2] = b'\x00\x00'
    for p in range(2, isqrt(n) + 1):
        if sieve[p]:
            sieve[p*p:n+1:p] = b'\x00' * ((n-p*p)//p + 1)
    return sum(sieve)

for x in (100, 1000, 10000, 100000, 1000000):
    actual = prime_count(x)
    estimate = x / log(x)
    print(x, actual, round(estimate, 2),
          round(actual / estimate, 6))

进一步推论：若 \(p_n\) 是第 \(n\) 个素数，则由素数定理可以反推出 \(p_n\sim n\ln n\)。它给出了第 \(n\) 个素数所在规模的估计。
