LAGRANGE MULTIPLIER METHOD

约束之下，
如何寻找极值？

拉格朗日乘数法并不是一套神秘公式。它表达的是一个很直观的事实： 当你已经无法沿着约束继续改善目标时，目标函数与约束的梯度必然平行。

∇f = λ∇g

01 · The problem

普通极值与约束极值，差别在哪里？

没有约束

变量可以向任意方向移动。内部极值点处，函数已经没有任何一阶上升方向，因此通常满足：

∂f/∂x = 0，∂f/∂y = 0
也就是 ∇f = 0

存在约束

如果必须满足 x + y = 1，你就只能沿着这条直线移动。极值点处的梯度不一定为零，因为有些方向根本不允许走。

允许的移动方向
被约束条件限制
拉格朗日法真正寻找的不是“所有方向都走不动”的点，而是“沿着约束允许的方向已经无法继续改善”的点。

02 · Geometry

为什么两个梯度必须平行？

把目标函数 f(x, y) 想象成一组等高线。沿着同一条等高线移动，函数值保持不变；梯度 ∇f 垂直于等高线，指向增长最快的方向。

约束 g(x, y)=0 也是一条曲线，它的梯度 ∇g 同样垂直于这条曲线。

在约束极值点，目标函数的等高线刚好与约束曲线相切。两条曲线拥有相同的切线方向，因此它们的法向量必然平行：

∇f = λ∇g
f 的等高线 约束 g=0 平行梯度

03 · The method

把几何关系变成可计算的方程

要在约束 g(x,y)=0 下求 f(x,y) 的极值，引入一个新变量 λ，并构造拉格朗日函数：

L(x, y, λ) = f(x, y) + λg(x, y)

然后让它对所有变量的一阶偏导都等于零：

∂L/∂x = 0
∂L/∂y = 0
∂L/∂λ = g(x,y) = 0

有些教材写成 L=f−λg，也完全正确。λ 本来就是未知数，整体改变符号不会改变最终的 x、y。

确定目标函数明确究竟要最大化或最小化哪个量。
把约束改写成等于零例如 x+y=1 改写为 g(x,y)=x+y−1=0。
构造拉格朗日函数写出 L=f+λg；每增加一个等式约束，就增加一个乘数。
求偏导并解方程组得到所有候选点，而不是直接宣布得到了极值。
比较并验证检查目标函数值、边界、不可微点以及极值是否真的存在。

04 · Worked example

完整例题：直线上距离原点最近的点

求函数 f(x,y)=x²+y² 在约束 x+y=1 下的最小值。

先理解它在问什么

x²+y² 是点 (x,y) 到原点距离的平方。因此题目其实是在直线 x+y=1 上，寻找距离原点最近的点。

构造拉格朗日函数

g(x,y)=x+y−1=0

L=x²+y²+λ(x+y−1)

求偏导

∂L/∂x = 2x + λ = 0
∂L/∂y = 2y + λ = 0
∂L/∂λ = x + y − 1 = 0

解方程组

前两个方程相减得到 2x−2y=0，所以 x=y。再代入 x+y=1：

x = y = 1/2

代回目标函数：

f(1/2, 1/2) = 1/4 + 1/4 = 1/2
最小值是 1/2，在点 (1/2, 1/2) 处取得。
动手改变约束：x+y=c 拖动滑块
约束 c1.0
最优点 x=y0.50
最小值 f0.50

规律是：最优点为 (c/2, c/2)，最小值为 c²/2。约束线离原点越远，能接触到的最小圆也越大。

为什么没有最大值？

直线 x+y=1 可以无限延伸。例如 x=100、y=−99 仍然满足约束，但 x²+y² 已经非常大。因此它有最小值，却没有最大值。

05 · Meaning of λ

λ 不只是一个辅助变量

在经济学和工程优化中，λ 通常反映：如果把约束稍微放宽一点，最优目标值会改变多少。

λ 常被称为影子价格（shadow price）：它衡量一单位额外资源对最优结果的边际价值。

具体正负号会受到 L=f+λg 或 L=f−λg 写法的影响，但它表达的“约束敏感度”不变。

06 · More constraints

存在多个约束时怎么办？

如果同时存在两个等式约束 g₁=0、g₂=0，就为它们分别引入 λ₁、λ₂：

L = f + λ₁g₁ + λ₂g₂

∇f = −λ₁∇g₁ − λ₂∇g₂

直观上，目标函数的梯度必须落在所有约束梯度所张成的方向之中。每增加一个等式约束，就增加一个拉格朗日乘数。

07 · AI & Machine Learning

拉格朗日乘数法在 AI 中解决什么问题？

机器学习训练通常是在最小化预测误差，但真实系统往往还有复杂度、概率归一化、安全、资源和公平性等限制。拉格朗日方法把这些限制转化为可以和模型参数一起优化的“价格”。

L(θ, λ) = Loss(θ) + λ · Constraint(θ)
λ 可以理解为“违反约束的价格”：约束越紧、越容易被突破，它对训练方向的影响就越大。

正则化与权重衰减

限制参数规模 ‖θ‖²≤C，可以转化为：

Loss(θ) + λ‖θ‖²

L2 正则化中的 λ，就是模型复杂度的价格。λ 越大，模型越偏向较小参数；λ 过小容易过拟合，过大则可能欠拟合。

支持向量机 SVM

SVM 给每个分类约束分配一个乘数 αᵢ。最终：

w = Σ αᵢyᵢxᵢ

多数样本的 αᵢ=0；只有边界附近 αᵢ>0 的样本真正决定分类面，它们就是支持向量。

概率模型与最大熵

概率必须满足 Σpᵢ=1。拉格朗日乘数可以在最大似然或最大熵推导中强制归一化，并导出指数族分布。

p(x) ∝ exp(Σ λₖfₖ(x))

Softmax、Logistic Regression、最大熵模型和条件随机场都与这套结构密切相关。

带约束的深度学习

除准确率外，还可以约束模型大小、推理延迟、显存、功耗、稀疏度、单调性或不同群体之间的误差差异。

Loss + Σ λₖgₖ(θ)

原始—对偶优化会交替更新模型参数 θ 和约束价格 λₖ，让被违反的约束逐渐获得更大权重。

安全强化学习

智能体既要最大化奖励，也要把碰撞、能耗或其他风险控制在预算内：

Reward − λ(Risk − Budget)

风险超出预算时，λ 上升，策略会更重视安全。这是约束马尔可夫决策过程（CMDP）的核心思路之一。

鲁棒优化与最优传输

对抗训练会限制输入扰动 ‖δ‖≤ε；最优传输要求搬运方案保持两端概率质量守恒。

min θ · max ‖δ‖≤ε Loss(θ,x+δ)

拉格朗日对偶可用于处理扰动边界、Wasserstein 距离、域适应和分布鲁棒优化中的约束。

它和梯度下降是什么关系？

两者解决的是不同层面的问题：梯度下降告诉我们参数应该往哪个方向更新；拉格朗日方法告诉我们存在硬性限制时，应该优化什么目标。实际训练中，通常仍然使用梯度下降来优化构造出来的拉格朗日函数。

拉格朗日乘数法并不是反向传播的基础。它主要用于“模型既要降低损失，又必须满足约束”的场景。

08 · Pitfalls

解出方程，不等于已经找到极值

  • 候选点不一定是极值点。它可能是最大值、最小值，也可能两者都不是。
  • 极值可能不存在。约束集合如果不封闭或无界，函数值可能无限增大或逼近却无法取得。
  • 别漏掉边界和不可微点。一阶条件只覆盖满足常规光滑条件的候选点。
  • 警惕 ∇g=0。约束本身在该点退化时，标准拉格朗日条件可能无法捕捉答案。
  • 不等式约束需要 KKT 条件。当约束形如 g(x)≤0 时，要使用更一般的 Karush–Kuhn–Tucker 条件。

One sentence summary

最后只记住这一句话

在约束极值点，目标函数的梯度必须落在约束梯度所张成的方向中。

单个约束时，就是最熟悉的 ∇f=λ∇g。
